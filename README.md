# 🎉 Events Webpage

A simple HTML project that showcases upcoming events like photo galleries, fashion sales, and stores in a clean, beginner-friendly webpage.

## ✏ About the Project
This webpage is built entirely with HTML to display event information, banners, and contact details.  
It is designed to help beginners practice structuring content, adding images, headings, and formatting text.

## 📌 Features
- Upcoming events section
- Event descriptions with images
- Contact information
- Simple, dark-themed design
- Fully static HTML (no CSS/JS yet)
